# Enterprise Visual & Style Upgrade

This package applies the visual-maturity specification to the Hotfix 7 UX10 baseline.

Implemented in this increment:
- unified enterprise SVG iconography across navigation and page headers
- notification unread-state cleanup when the notification center is opened
- persistent Light / Dark / System appearance selector with pre-hydration theme application
- compact profile utility menu consolidating language, appearance and sign-out
- professional back/forward icon treatment and breadcrumb chevrons
- semantic status pills with icon + text + color
- branded drag-and-drop finance-data importer
- human-readable mapping criteria and mapping KPI summary
- evidence-oriented three-column TP Copilot workspace
- richer Control Tower KPI and governance interaction treatment
- reconciliation process-flow visualization
- policy lifecycle stepper and percentage formatting
- P&L KPI/technical-lineage presentation and finance-number formatting
- comprehensive dark-theme styling for shell, forms, grids, modals, tables and cards

Business logic, deterministic calculations, permissions, maker-checker controls and external qualification boundaries were intentionally preserved.
