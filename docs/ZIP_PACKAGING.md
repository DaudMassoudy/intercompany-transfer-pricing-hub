# ZIP Packaging Specification — v2.0.0-rc.1

Artifact: `Enterprise_OTP_Platform_v2.0.0-rc.1.zip`.

Required root launchers: `START_DEMO.bat`, `START_OTP.bat`, `START_DEV.bat`, `STOP_OTP.bat`, `RESET_DEMO.bat`, `BACKUP_OTP.bat`, `RESTORE_OTP.bat`, `STATUS_OTP.bat`.

The ZIP includes complete source code, Docker configuration, Alembic migrations, n8n workflow JSON, sample datasets, fictional reference PDFs, tests, validation evidence and documentation.

It excludes node_modules, Python virtual environments, `.next`, caches, bytecode, runtime databases, generated `.env`, real credentials and Docker volumes.
