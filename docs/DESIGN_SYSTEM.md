# OTP Enterprise Design System

Core principles: clarity, restrained finance-grade visual language, role awareness, evidence-first workflows, accessible focus states, progressive disclosure and consistent action feedback.

Shared primitives now include App Shell, responsive navigation drawer, contextual breadcrumbs, DataGrid behavior, cards, KPI blocks, status pills, modal dialogs, notification/task surface, form fields, semantic notices and density controls.

Spacing tokens: 4/8/12/16/24/32/48. Semantic status uses text plus color; green=controlled/success, amber=attention/pending, red=blocked/error, grey=inactive/archive, blue=informational/active.
