# Production Go-Live Plan

Recommended promotion sequence:

**Release Candidate → Enterprise Pilot → ERP Sandbox → TP UAT → Finance UAT → Security Pen Test → Production-Scale Performance Test → Parallel Close 1 → Parallel Close 2 → Parallel Close 3 if required → DR Exercise → Cutover Approval → Production → 4–6 Week Hypercare.**

Each stage requires objective exit evidence. Failed controls return the release to engineering; no stage is passed by declaration alone.
