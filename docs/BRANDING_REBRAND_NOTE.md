# Product Branding Update — Intercompany Transfer Pricing Hub

The user-facing product brand has been updated from **OTP Control Tower / Enterprise OTP Platform** to:

**Intercompany Transfer Pricing Hub**  
*Operations, Analytics & Governance*

German supporting subtitle: **Operative Prozesse, Analysen & Governance**.

The change is intentionally limited to product-facing branding, current documentation, browser metadata, login branding, application shell, and launcher/report headings. Internal technical identifiers such as `otp_token`, `otp_theme`, `otp_language`, Docker/package identifiers, `*.bat` filenames, API routes, database identifiers, and the `@otp.local` demo account domain are retained to avoid unnecessary compatibility risk.

Historical specification/evidence files may retain the former product name where it identifies the historical release or baseline that was originally qualified.
