# Guided portfolio demo

All examples use synthetic demonstration data.

1. Launch with `START_DEMO.bat` on Windows and Docker Desktop.
2. Open the **Control Tower** to inspect legal entities and margin-policy exceptions.
3. Browse **Entities**, **Master Data Catalog** and **Data Imports**.
4. Load `sample_data/20_Authoritative_PnL_Demo.csv` through Data Imports.
5. Review validation/mapping/allocations and publish the demo P&L.
6. Inspect **Forecasts**, **Variance Analysis** and **Simulation**.
7. Follow a proposed **True-Up → Approval → Journal → ERP Posting → Reconciliation**.
8. Inspect documents, audit evidence and workflow orchestration.

Illustrative expected DE01 result reported in original project documentation: EUR 111.9m revenue, EUR 2.58489m EBIT, 2.31% ROS and EUR 1.89111m adjustment. This is not real client data.

Demo users are seeded for presentation and are not secure identities. Only use the demo on a trusted local environment.
