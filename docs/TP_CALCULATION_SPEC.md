# TP Calculation Specification
Authoritative engine: Python.

- EBIT = Revenue - COGS - OPEX
- ROS = EBIT / Revenue
- Target EBIT = Revenue * Target ROS
- True-up = Target EBIT - Actual EBIT
- Control: journal debit = journal credit = absolute approved adjustment
- Reconciliation difference = posted amount - absolute approved adjustment

Golden Germany case: Revenue 111.9m, COGS 80m, OPEX 29.31511m -> EBIT 2.58489m -> ROS 2.31% -> true-up to 4% = 1.89111m.
