# Demo Dataset Specification

Synthetic group:

- NL01 - Principal
- DE01 - Limited-risk distributor
- FR01 - Limited-risk distributor
- IT01 - Limited-risk distributor
- PL01 - Contract manufacturer
- NL02 - Shared services

The `/sample_data` bundle contains 19 governed Excel contracts plus a 50,000-row CSV stress-test GL generator/output. The compact GL XLSX is deliberately bounded for portable ZIP size. IDs are consistent across entities, partners, policies, mappings, true-ups, journals and posting confirmation.

Golden DE01 case: revenue EUR111.9m; EBIT EUR2.58489m; ROS 2.31%; target 4.00%; true-up EUR1.89111m; forecast 2.47%.
